# Self-Storage Demo Implementation

This is a deliberately small, non-production implementation used to validate the framework lifecycle on the real Self-Storage project.

## Run

Open `index.html` directly in a browser.

## Implemented source scope

- FR-SELF-STORAGE-001: facility/unit discovery.
- FR-SELF-STORAGE-002: reservation inputs and local demo submission.

## Not implemented

Payment, authentication, database persistence, API integration, status transitions, notifications, and other unresolved production behavior are intentionally excluded.
