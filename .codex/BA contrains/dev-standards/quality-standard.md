# Quality Development Standard

**Version:** `v1.0`
**Status:** `ACTIVE`
**Scope:** General implementation quality

## Purpose

Define quality expectations for approved implementation work.

## Rules

1. Implementation MUST satisfy approved completion criteria.
2. Changes SHOULD be reviewable, traceable, and reproducible.
3. Quality checks MUST be proportional to approved scope and applicable standards.
4. A quality practice MUST NOT become a new product requirement unless explicitly stated.
5. Defects MUST be recorded with enough context to identify affected approved scope.
6. Quality findings MUST distinguish implementation defects from requirement gaps.

## Boundary

This standard governs engineering quality. It does not invent features or acceptance criteria that are not otherwise approved.
